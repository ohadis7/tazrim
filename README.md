# תזרים יבוא

כלי לתכנון תזרים ומימון לעסקאות יבוא: כמה מימון צריך לכל עסקה, לכמה זמן, וכמה זה עולה.
כולל ניהול לקוח, הצעת מחיר, שורות פריטים, הזמנה ותזכורות לכל פרויקט.

**פתיחה:** https://ohadis7.github.io/tazrim/

הדף רץ כולו בדפדפן. הנתונים שמזינים נשמרים רק בדפדפן של מי שמשתמש בו ולא נשלחים לשום שרת.

המאגר הזה מכיל רק את הדף המפורסם. הקוד, הבדיקות וההיסטוריה נמצאים במאגר פרטי.
