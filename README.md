# תזרים יבוא

**זהו פרויקט לדוגמה לניהול תזרים מזומנים של חברה.**
הדוגמה בנויה סביב חברה שמייבאת ציוד מחו"ל: היא משלמת לספק חודשים לפני שהלקוח משלם לה, והכלי מראה מראש כמה מימון צריך, לכמה זמן, וכמה זה עולה.

**פתיחה:** https://ohadis7.github.io/tazrim/

## מה יש בכלי

- **תחזית תזרים** לפי חודשים או שבועות: כמה נכנס, כמה יוצא, ומה היתרה בסוף כל תקופה. כל סעיף אפשר לכבות ולהדליק כדי לראות את ההשפעה.
- **שיא צורך המימון**, ימי הפער במינוס, עלות המימון בריבית, ובדיקה מול מסגרת האשראי בבנק.
- **תרחיש לחץ**: מה קורה אם הלקוח מאחר בתשלום או שהשקל נחלש.
- **ניהול פרויקט לכל עסקה**: פרטי לקוח, הצעת מחיר עם שורות פריטים והשוואה להצעה הקודמת, הזמנה, עדכוני התקדמות ותזכורות.

הדף נפתח עם שתי עסקאות לדוגמה, כך שאפשר לנסות אותו מיד.

## פרטיות

הדף רץ כולו בדפדפן. הנתונים שמזינים נשמרים רק בדפדפן של מי שמשתמש בו ולא נשלחים לשום שרת.

המאגר הזה מכיל רק את הדף המפורסם. הקוד, הבדיקות וההיסטוריה נמצאים במאגר פרטי.
